The LogoMinter API

Generate and refine logos from your own product. The API mirrors what you can do in the app — describe a brand, get back a set of concepts, and iterate — over plain JSON.

Before you begin

The API is currently in private preview. Keys are issued on request while we finalize rate limits and pricing. Join the waitlist and we'll reach out with credentials and a sandbox to build against.

Authentication

Every request is authenticated with a bearer token in the Authorization header. Keep your key server-side — it can create billable generations.

# All requests go to
https://api.logominter.com/v1

# Pass your key as a bearer token
Authorization: Bearer lm_live_xxxxxxxxxxxx

Create a logo set

POST /v1/logos — submit a brief and receive several distinct concepts.

curl https://api.logominter.com/v1/logos \
  -H "Authorization: Bearer lm_live_xxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Northwind Coffee",
    "description": "A neighborhood roastery and cafe",
    "style": "warm, minimal, vintage",
    "count": 4
  }'

The response returns a set_id and an array of concepts, each with a preview URL and its own logo_id for refinement.

{
  "set_id": "set_9fA2...",
  "status": "complete",
  "concepts": [
    { "logo_id": "logo_01", "preview_url": "https://cdn.logominter.com/..." },
    { "logo_id": "logo_02", "preview_url": "https://cdn.logominter.com/..." }
  ]
}

Refine a concept

POST /v1/logos/{logo_id}/refine — send a plain-language instruction to adjust an existing concept.

curl https://api.logominter.com/v1/logos/logo_02/refine \
  -H "Authorization: Bearer lm_live_xxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{ "instruction": "warmer palette, lighter weight wordmark" }'

Retrieve & export

GET /v1/logos/{logo_id} — fetch the current state of a logo and links to its downloadable assets.

Formats

PNG at multiple sizes plus vector-ready output, each in light and dark variants.

Webhooks

Register a callback URL to be notified when a large batch finishes instead of polling.

Idempotency

Send an Idempotency-Key header so retried requests never double-charge.

Rate limits & errors

Preview keys are capped at a modest burst rate while we tune capacity. The API uses standard HTTP status codes — 401 for a bad key, 422 for an invalid brief, 429 when you're over the limit — and every error body includes a message and a code you can branch on.
